Ports

The reference implementation is hayahash.h (C99, single header). Nine bit-exact ports live in the same repository. All ten share one version number — currently v0.4.5 — so a given version is the same algorithm everywhere.

Conformance is enforced, not assumed: every port's test suite checks the SMHasher3 verification value (0xF3C4A9B4) and a shared table of known-answer vectors generated from the C header. Nightly differential fuzzing replays a fresh randomized C-reference corpus — exhaustive lengths 0–384, boundary-biased lengths up to 128 KiB — through every language port, both JavaScript engines included. The MIPS64 assembly port is not in the nightly matrix and relies on the shared vectors instead.

Remember the status: experimental, digests may still change between versions. Pin your version.

C

Copy the header into your project; there are no dependencies. It is also attached to every release:

curl -LO https://github.com/thevilledev/hayahash/releases/latest/download/hayahash.h
#include "hayahash.h"

uint64_t h = hayahash64(buf, len, seed);

Rust

hayahash on crates.io, no_std compatible:

cargo add hayahash
let h = hayahash::hayahash64(buf, seed);

Go

Module github.com/thevilledev/hayahash/go:

go get github.com/thevilledev/hayahash/go
import hayahash "github.com/thevilledev/hayahash/go"

h := hayahash.Hash64(buf, seed)

Zig

Zig 0.16. Fetch the packaged module from the release:

zig fetch --save https://github.com/thevilledev/hayahash/releases/download/v0.4.5/hayahash-zig-0.4.5.tar.gz

Then in build.zig:

const hayahash = b.dependency("hayahash", .{});
exe.root_module.addImport("hayahash", hayahash.module("hayahash"));
const hayahash = @import("hayahash");

const h = hayahash.hayahash64(buf, seed);

Java

io.github.thevilledev:hayahash on Maven Central, Java 17+:

<dependency>
  <groupId>io.github.thevilledev</groupId>
  <artifactId>hayahash</artifactId>
  <version>0.4.5</version>
</dependency>
import io.github.thevilledev.hayahash.Hayahash;

long h = Hayahash.hash64(buf, seed);

C# / .NET

Hayahash on NuGet, .NET 8+:

dotnet add package Hayahash
using Hayahash;

ulong h = Hayahash.Hash64(buf, seed);

Python

hayahash on PyPI, CPython 3.9+. A C extension wraps the reference header directly; releases ship manylinux/musllinux, Windows, and macOS wheels:

pip install hayahash
from hayahash import hayahash64

h = hayahash64(buf, seed)

Swift

SwiftPM package, Swift 5.9+. The package lives in a monorepo subdirectory, so consume it as a local path dependency or via the hayahash-swift-0.4.5.tar.gz release asset, which has Package.swift at its root:

import Hayahash

let h = Hayahash.hash64(buf, seed: 0)

JavaScript / TypeScript

hayahash on npm. The fast path is the reference header compiled to a ~1.5 KB WebAssembly module, with a pure-JS fallback; both engines are tested and fuzzed:

npm install hayahash
import { hayahash64 } from "hayahash";

const h = hayahash64(buf, seed); // unsigned 64-bit BigInt

MIPS64 assembly

Hand-written hayahash.S, n64 ABI, tested under qemu-mips64el against the shared vectors. Copy mips/hayahash.S and its hayahash.h declaration into your build:

#include "hayahash.h" /* mips/hayahash.h */

uint64_t h = hayahash64(buf, len, seed);

Repository layout

hayahash.hC99 reference, single header, public domain
rust/ go/ zig/ java/ csharp/ python/ swift/ js/ mips/one directory per port, each with its own KAT test suite
tests/quality and benchmark harnesses; ChibiHash v1/v2 sources vendored for self-contained comparisons
tests/smhasher3/SMHasher3 adapter, pinned build harness (GPL-3.0-or-later, never in release artifacts)
tests/differential/randomized corpus generator for the nightly cross-port fuzz
tests/wasm/baseline-wasm32 shootout and wasm-vs-native bit-exactness check
docs/ paper/design/quality/ports docs; working paper, evidence register, archived runs
