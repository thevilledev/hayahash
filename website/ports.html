Ports

The reference implementation is hayahash.h. It is one C99 header. The repository contains nine bit-exact ports. All ten implementations share one version number, now v0.5.0. One version is the same algorithm in each language.

We do not assume conformance. We test it. The test suite of each port checks the SMHasher3 verification value (0x65F2AC15). It checks a shared table of known-answer vectors from the C reference. A nightly differential fuzz makes a new random corpus from the C reference. The corpus has all lengths from 0 to 384. It has boundary-biased lengths up to 128 KiB. Each port must return the same hash values as the C reference. This includes the two JavaScript engines. The MIPS64 port is not in the nightly matrix. It uses the shared vectors.

hayahash is experimental. Hash values can change between versions. Pin your version.

C

Copy the header into your project. It has no dependencies. Each release includes the header as an asset:

curl -LO https://github.com/thevilledev/hayahash/releases/latest/download/hayahash.h
#include "hayahash.h"

uint64_t h = hayahash64(buf, len, seed);
hayahash128_t h128 = hayahash128(buf, len, seed);

Rust

The hayahash crate is on crates.io. It is no_std compatible:

cargo add hayahash
let h = hayahash::hayahash64(buf, seed);
let h128 = hayahash::hayahash128(buf, seed);

Go

The module is github.com/thevilledev/hayahash/go:

go get github.com/thevilledev/hayahash/go
import hayahash "github.com/thevilledev/hayahash/go"

h := hayahash.Hash64(buf, seed)
h128 := hayahash.Hash128(buf, seed)

Zig

The port needs Zig 0.16. Get the module from the release:

zig fetch --save https://github.com/thevilledev/hayahash/releases/download/v0.5.0/hayahash-zig-0.5.0.tar.gz

Then add this to build.zig:

const hayahash = b.dependency("hayahash", .{});
exe.root_module.addImport("hayahash", hayahash.module("hayahash"));
const hayahash = @import("hayahash");

const h = hayahash.hayahash64(buf, seed);
const h128 = hayahash.hayahash128(buf, seed);

Java

io.github.thevilledev:hayahash is on Maven Central. It needs Java 17 or later:

<dependency>
  <groupId>io.github.thevilledev</groupId>
  <artifactId>hayahash</artifactId>
  <version>0.5.0</version>
</dependency>
import io.github.thevilledev.hayahash.Hayahash;

long h = Hayahash.hash64(buf, seed);
Hayahash.Hash128 h128 = Hayahash.hash128(buf, seed);

C# / .NET

The Hayahash package is on NuGet. It needs .NET 8 or later:

dotnet add package Hayahash
using Hayahash;

ulong h = Hayahash.Hash64(buf, seed);
Digest128 h128 = Hayahash.Hash128(buf, seed);

Python

The hayahash package is on PyPI. It needs CPython 3.9 or later. A C extension wraps the reference header. Releases include wheels for Linux (manylinux and musllinux), Windows, and macOS:

pip install hayahash
from hayahash import hayahash128, hayahash64

h = hayahash64(buf, seed)
h128 = hayahash128(buf, seed)  # (lo, hi)

Swift

The port is a SwiftPM package. It needs Swift 5.9 or later. The package is in a subdirectory of the repository. Use one of two methods. Add the package as a local path dependency. Or use the hayahash-swift-0.5.0.tar.gz release asset. That archive has Package.swift at its root:

import Hayahash

let h = Hayahash.hash64(buf, seed: 0)
let h128 = Hayahash.hash128(buf, seed: 0)

JavaScript / TypeScript

The hayahash package is on npm. The fast path is the reference header compiled to WebAssembly, approximately 3 KB. A pure-JS fallback is included. The tests and the nightly fuzz cover the two engines:

npm install hayahash
import { hayahash128, hayahash64 } from "hayahash";

const h = hayahash64(buf, seed); // unsigned 64-bit BigInt
const h128 = hayahash128(buf, seed); // { lo, hi }

MIPS64 assembly

The port is hayahash.S, written by hand for the n64 ABI. Copy mips/hayahash.S and mips/hayahash.h into your build. The tests run it under qemu-mips64el against the shared vectors:

#include "hayahash.h" /* mips/hayahash.h */

uint64_t h = hayahash64(buf, len, seed);
hayahash128_t h128 = hayahash128(buf, len, seed);

Repository layout

hayahash.hThe C99 reference. One header. Public domain.
rust/ go/ zig/ java/ csharp/ python/ swift/ js/ mips/One directory for each port. Each port has its own KAT test suite.
tests/The quality and benchmark harnesses. The ChibiHash v1 and v2 sources are vendored here. So the comparisons are self-contained.
tests/smhasher3/The SMHasher3 adapter and the pinned build harness. GPL-3.0-or-later. Not in release artifacts.
tests/differential/The corpus generator for the nightly cross-port fuzz.
tests/wasm/The wasm32 shootout and the wasm-against-native bit-exactness check.
docs/ paper/The design, quality, and port documents. The working paper, the evidence register, and the raw evaluation records.
